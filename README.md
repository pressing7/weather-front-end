### 나만의 날씨 예보 사이트

## Front-end 개발 기말 과제

# 배포 링크
weather-front-end-ecru.vercel.app

# 주요 기능
**상세 날씨 정보:** OpenWeatherMap API를 연동하여 실시간 온도, 습도, 풍속 및 5일 예보 제공
**데이터 기반 옷차림 추천:** 현재 기온 데이터를 분석하여 적절한 옷차림을 LED 전광판으로 안내


# 기술 스택
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **API:** OpenWeatherMap API
- **Deploy:** Vercel
